# Orchestrator-Driven, Phase-Based Verification and Commit Guardrails

A cross-domain pattern mandates that all important project changes—API, endpoints, infrastructure—undergo orchestrator-driven, phase-gated verification with guardrails (e.g., clean code, test checks), preventing direct edits and ensuring secure, compliant releases.

## Evidence

- **facts**: Describes orchestrator-driven, phase-based verification protocols and guardrails as mandatory for all critical changes, with detailed documentation of protocols and incidents.
- **project_management**: Codex Delegate workflow enforces commit scoping, post-commit hygiene review, and separation of verification/recall, aligning with orchestrator-driven protocols.
- **design**: Unified security and endpoint standards rely on operational feedback and verification loops, feeding project incidents and credential requirements into design protocols.
