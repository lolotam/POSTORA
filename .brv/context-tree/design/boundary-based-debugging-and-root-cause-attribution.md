# Boundary-Based Debugging and Root Cause Attribution

Design and project management domains both emphasize a systematic, boundary-based approach to debugging and root cause analysis—tracing errors at each system interface to ensure accurate diagnostics and effective incident response.

## Evidence

- **design**: Documents boundary-based debugging and attribution, including real-world case studies (e.g., Instagram DM failures), highlighting root cause tracing at each system boundary.
- **project_management**: Retrospectives and process reviews document technical and process relationships, using boundary analyses to map frontend/backend responsibilities and incident causality.
